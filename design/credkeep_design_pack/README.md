# CredKeep — Production UI Design Specification Pack

**Contents:** 1 master token contract; 1 navigation map; 14 independently scoped component-family files; 58 individual phone screen specifications; Gemini/Codex Stitch MCP controller instructions; completion tracker CSV.

## Order of work
1. Review and approve `00_foundation/DESIGN_SYSTEM_MASTER.md`.
2. Generate `01_components/COMP-*` **individually** (small specimens, variants, no phone mockups).
3. Approve component appearance and states.
4. Generate `02_screens/<GROUP>/<ID>.md` **one native 390×884 frame at a time**, keeping important content within a 390×844 target where practical and honoring dynamic Android system insets.
5. Use `03_workflow/COMPLETION_TRACKER.csv` to prevent duplicates and false completion.
6. Export from Stitch and later integrate in Antigravity; do not rework backend while in design mode.

This is a prepared specification, not actual Stitch exports or proof of connected MCP access. Sensitive loans/documents in screens are synthetic examples.
